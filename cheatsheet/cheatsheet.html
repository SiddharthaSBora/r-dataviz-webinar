ggplot2 & friends, one-page cheatsheet

The grammar

ggplot(data, aes(x, y)) +   # data + mapping
  geom_*() +                # what to draw
  scale_*() +               # how aes maps to visuals
  facet_*() +               # small multiples
  coord_*() +               # coordinate system
  labs() + theme_*()        # labels + look

Each + adds a layer. Plots are objects: save with p <- ..., extend later with p + ....

Tidy first

# wide -> long (what ggplot wants)
pivot_longer(df, -id,
  names_to = "key",
  values_to = "value")

# long -> wide
pivot_wider(df,
  names_from = key,
  values_from = value)

Color, deliberately

# colorblind-safe, continuous
scale_color_viridis_c()
scale_fill_viridis_c()

# colorblind-safe, discrete
scale_color_viridis_d(end = .85)

# manual (exact control)
scale_color_manual(values = okabe_ito)

Avoid rainbow/jet colormaps. Encode order in lightness, not hue.

Facets

facet_wrap(~var)              # one var
facet_grid(rows ~ cols)       # two vars
facet_wrap(~var,
  scales = "free_y")          # independent scales

Accessibility

  • Pair color with a 2nd channel: linetype=, shape=.
  • Test with colorspace::deutan(plot).
  • Add alt text in Quarto: #| fig-alt: "...".
  • Survives grayscale = survives most CVD.

Number formatting (scales)

scale_y_continuous(
  labels = label_comma())      # 1,000,000
label_dollar()   label_percent()
label_number(accuracy = 0.1)

Maps (sf)

library(sf); library(tigris)
options(tigris_use_cache = TRUE)

geo <- counties("WV", cb = TRUE)
ggplot(geo) + geom_sf()

# right projection for the lower 48
coord_sf(crs = 5070)          # Albers

Choropleth: join data, map to fill. tidycensus attaches geometry to ACS data.

Combine (patchwork)

p1 + p2          # side by side
p1 / p2          # stacked
(p1 + p2) / p3   # nested
... + plot_layout(guides = "collect")
... + plot_annotation(tag_levels = "A")
